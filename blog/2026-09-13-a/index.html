架构

一图胜千言

个人创建 QQ Bot 就要在自己的服务器上安装 AstrBot 与 NapCat, 并暴露端口用于反向 WebSocket 通信

安装并启动 AstrBot 与 NapCat

服务器系统为阿里云 Ubuntu Server 24.04 (2 Core / 2 GB RAM / 40 GB Disk)

  1. 创建 Swap: 划分 2G 硬盘用于内存交换, 预防内存小导致安装崩溃
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab

free -h
swapon --show
  1. 安装 uv: AstrBot 推荐使用 uv 管理 Python 等依赖
curl -LsSf https://astral.sh/uv/install.sh | sh

# 可能要配置环境变量
export PATH="/root/.local/bin:$PATH"
uv --version
  1. 安装 AstrBot 并初始化: 需要 Python 3.12 或更高版本
# 串行下载并构建
UV_CONCURRENT_DOWNLOADS=1 \
UV_CONCURRENT_BUILDS=1 \
UV_HTTP_TIMEOUT=60 \
uv tool install astrbot --python 3.12 --index-url https://pypi.org/simple

mkdir -p /opt/astrbot
cd /opt/astrbot
astrbot init --yes
  1. 创建 AstrBot systemd 服务: 开机自启和异常重启等配置
  • 配置文件 /etc/systemd/system/astrbot.service:
[Unit]
Description=AstrBot QQ Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/astrbot
Environment=PATH=/root/.local/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin
ExecStart=/root/.local/bin/astrbot run
Restart=on-failure
RestartSec=10
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
  • 应用配置并启动 AstrBot:
systemctl daemon-reload
systemctl enable --now astrbot
systemctl status astrbot
  1. 安装 Docker 与 Docker Compose
apt-get update
DEBIAN_FRONTEND=noninteractive apt-get install -y docker.io docker-compose

systemctl enable --now docker
docker --version
  1. 拉取 NapCat 镜像
# 使用镜像源 docker.1ms.run
docker pull docker.1ms.run/mlikiowa/napcat-docker:latest
docker tag docker.1ms.run/mlikiowa/napcat-docker:latest mlikiowa/napcat-docker:latest
  1. 启动 NapCat
# 映射到 Docker 容器里面, 用于持久化配置和 QQ 数据
mkdir -p /opt/napcat/napcat/config
mkdir -p /opt/napcat/ntqq

docker run -d \
  --name napcat \
  --restart always \
  --network host \
  -e NAPCAT_UID=0 \
  -e NAPCAT_GID=0 \
  -e MODE=astrbot \
  -v /opt/napcat/napcat/config:/app/napcat/config \
  -v /opt/napcat/ntqq:/app/.config/QQ \
  mlikiowa/napcat-docker:latest

docker ps

SSH 隧道转发以使用 WebUI

  1. AstrBot WebUI
ssh -L 6185:127.0.0.1:6185 root@[Server IP]
  • 访问本地机器 http://127.0.0.1:6185
  1. NapCat WebUI
ssh -L 6099:127.0.0.1:6099 root@[Server IP]
  • 访问本地机器 http://127.0.0.1:6099
  • 登录的 token 会在 NapCat 启动日志中
  1. 同时访问两个 WebUI
ssh -L 6185:127.0.0.1:6185 -L 6099:127.0.0.1:6099 root@[Server IP]

配置 AstrBot OneBot v11

在 WebUI 的机器人中创建 OneBot v11 实例:

  • 反向 WebSocket 主机地址: 0.0.0.0
  • 反向 WebSocket 端口: 6199
  • 反向 WebSocket URL: ws://[Server IP]:6199/ws
  • Token: 仅在 NapCat 网络配置中启用 Token 时填写, 双方必须一致
