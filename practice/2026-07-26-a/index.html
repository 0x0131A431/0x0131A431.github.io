Tip: 因 DHCP 虚拟机 IP 变动

网络模式使用NAT, 通过 MAC 地址绑定一个固定的 DHCP IP (DHCP Reservation).

C:/ProgramData/VMware/vmnetdhcp.conf 末尾添加:

# Added at 07/26/26 16:24:51

    hardware ethernet 00:0C:29:F8:3D:61;        # 虚拟机 MAC 地址
    fixed-address 192.168.129.100;              # 虚拟机 NAT 网段内 IP
}
# End

然后重启宿主机 VMware DHCP Service, 重启虚拟机.

如果切换到桥接(Bridge), 再切回 NAT 要检查 MAC 地址有没有变.

  3. 重启 VSCode.

socket

socket 是什么:

processA -> socket(TCP/UDP) -> ...... -> socket(TCP/UDP) -> processB

socket 的两大类:

Stream socket (流式套接字)Datagram socket (数据报套接字)
底层协议TCP (传输控制协议)UDP (用户数据报协议)
连接状态面向连接(通信前必须先建立连接)无连接(随时可以发送数据, 无需建立连接)
可靠性可靠, 保证数据无差错, 不丢失, 不重复, 按序到达不可靠, 只尽最大努力交付
数据边界无数据边界(字节流), 传输字节流, 可能发生粘包或拆包有数据边界(报文), 每次发送一个独立的报文, 接收时也以报文为单位
传输效率较低, 拥塞控制, 流量控制和确认应答等机制开销较大较高, 没有复杂的控制机制
通信模型一对一一对一, 一对多和多对多
适用场景准确性要求高的场景实时性要求高的场景

数据封装(Data Encapsulation)

OSI 7 层模型:

层级功能数据单元
7. 应用层用户与网络的直接接口数据 (Data)
6. 表示层数据格式转换, 加密解密, 压缩数据 (Data)
5. 会话层建立, 管理和终止会话连接数据 (Data)
4. 传输层端到端可靠/不可靠传输, 负责分段数据段 (Segment)
3. 网络层寻址和路由选择, 跨网络传输数据包 (Packet)
2. 数据链路层局域网内传输, 错误检测数据帧 (Frame)
1. 物理层原始比特流传输, 物理介质接口比特 (Bit)

数据封装的过程:

层级发送端操作添加的信息产出数据单元
7. 应用层用户应用程序产生原始数据无数据 (Data)
6. 表示层将数据格式化为通用格式表示层头部数据 (Data)
5. 会话层建立通信会话, 添加会话标识会话层头部数据 (Data)
4. 传输层将数据拆分为合适大小的片段, 添加源/目的端口号传输层头部数据段 (Segment)
3. 网络层添加源/目的IP地址, 决定最佳传输路径网络层头部数据包 (Packet)
2. 数据链路层添加源/目的MAC地址, 并添加尾部用于错误检测链路层头部 + 尾部数据帧 (Frame)
1. 物理层将帧转换为比特流, 通过物理介质发送无比特 (Bit)
  • Tips
    • 发送方自顶向下封装(Encapsulation), 接收方自底向上解封装(De-encapsulation)
    • 头部(Header): 每层添加的"标签", 包含该层所需的控制信息(地址, 序号, 类型等), 接收端解封装时, 逐层剥离并读取对应头部
    • 尾部(Trailer): 在末尾添加尾部, 校验数据是否损坏
    • 模型仅助于理解, 如实际上表示层和会话层的功能通常由应用程序库(如SSL/TLS, SOCKS)或操作系统API隐式处理, 并不会在数据上添加独立的"表示层头部"或"会话层头部"

IPv4 与 IPv6

IPv4(Internet Protocol Version 4, 互联网协议第四版)的地址由4个字节(Bytes)组成, 文本格式为点分10进制:

二进制数: 11000000 10101000 00000001 00000001
文本表示: 192.168.1.1

IPv6的地址由16个字节组成, 文本格式为冒号分16进制:

二进制数: 00100000 00000001 00001101 10111000 ... (共 16 Bytes)
文本表示: 2001:0DB8:0000:0000:0000:0000:0000:0001
压缩形式: 2001:DB8::1

子网 Sub-Network

子网始于对 IPv4 地址枯竭的缓冲方案, 使用也以 IPv4 为主

子网是对一个大的IP网络在逻辑上进行再划分

  • 减少广播域, 提升性能: 广播包只在子网内部传播, 不会扩散到整个大网
  • 安全性: 不同子网间的通信必须经过路由器, 可以在路由器上设置访问控制, 隔离敏感区域
  • 节约IP地址: 通过可变长子网掩码(VLSM), 可以根据每个子网的实际主机数量灵活分配地址, 避免浪费

子网使用子网掩码进行再划分. IPv4 子网掩码由4个字节组成, 连续的 1 表示网络位(包含子网号), 连续的 0 表示主机位:

IP 二进制数: 11000000 10101000 00000001 00000001
子网掩码: 255.255.255.0
文本表示: 192.168.1.0/24  (前24位是网络位与子网号, 后8位是主机位)

192.168.1.1 与 192.168.1.2 属于子网掩码 255.255.255.0 下子网的不同机器

通过增加子网掩码 0 的位数来合并扩大网段, 如 192.168.0.0/16, 即子网掩码 255.255.0.0

端口号 Port-Number

一个2字节整数, 用于标识正在进行网络通信的进程, 与 IP 组合完整文本格式为 ip:port

192.168.1.1:8080 标识了主机 192.168.1.1 中 8080 端口正在进行网络通信的进程

字节序(Byte Order)

多字节数据在内存中存储的顺序

  • 假设有4字节整数 0x12345678
    • 大端序(Big-Endian)高位字节存放在内存的低地址处, 低位字节存放在高地址处: 12 34 56 78
    • 小端序(Little-Endian)低位字节存放在内存的低地址处, 高位字节存放在高地址处: 78 56 34 12

网络协议使用大端序, 操作系统使用小端序, 这就要求传输时互相转换

socket 接口数据结构

int socket_descriptor;

/** addrinfo: 地址查询结构
 * 初始化查询结构 struct addrinfo hints; 需要 ai_family, ai_socktype 和 ai_flags 参数
 * 初始化查询结果指针 struct addrinfo *res; 指向查询结果
 * 查询 int status = getaddrinfo(NULL, "8080", &hints, &res);
 */
struct addrinfo {
    int ai_flags;                       // AI_PASSIVE, AI_CANONNAME 等标志位
    int ai_family;                      // AF_INET, AF_INET6, AF_UNSPEC
    int ai_socktype;                    // SOCK_STREAM (TCP), SOCK_DGRAM (UDP)
    int ai_protocol;                    // 传 0 代表 "任意"
    size_t ai_addrlen;                  // ai_addr 指向的地址结构的大小(Bytes)
    struct sockaddr *ai_addr;           // 实际指向 sockaddr_in 或 sockaddr_in6
    char *ai_canonname;                 // 权威主机名
    struct addrinfo *ai_next;           // 链表指针, 下一个候选结果
};

/** sockaddr: 通用地址的"基类", 作为统一的第一参数类型: struct sockaddr *; */
struct sockaddr {
    unsigned short sa_family;           // 地址族: AF_INET 或 AF_INET6
    char           sa_data[14];         // 14 字节的协议地址(原始数据)
};

/** IPv4 专用 */
struct sockaddr_in {
    short int          sin_family;      // 地址族, 固定为 AF_INET
    unsigned short int sin_port;        // 端口号, Network Byte Order (大端序)
    struct in_addr     sin_addr;        // IPv4 地址
    unsigned char      sin_zero[8];     // 填充, 用 memset 全部置零
};
struct in_addr {
    uint32_t s_addr;                    // 32 位 (4 字节) IP 地址, Network Byte Order
};

/** IPv6 专用 */
struct sockaddr_in6 {
    u_int16_t       sin6_family;        // 地址族, 固定为 AF_INET6
    u_int16_t       sin6_port;          // 端口号, Network Byte Order
    u_int32_t       sin6_flowinfo;      // IPv6 流信息
    struct in6_addr sin6_addr;          // IPv6 地址 (16 字节)
    u_int32_t       sin6_scope_id;      // Scope ID
};
struct in6_addr {
    unsigned char s6_addr[16];          // 16 字节的 IPv6 地址
};

/** 通用容器 */
struct sockaddr_storage {
    sa_family_t ss_family;              // 地址族 (AF_INET 或 AF_INET6)
    char     __ss_pad1[_SS_PAD1SIZE];
    int64_t  __ss_align;
    char     __ss_pad2[_SS_PAD2SIZE];
};

addrinfo (链表, 每个节点一组地址)
   └── ai_addr ──► sockaddr (抽象基类)
                       ↑
          ┌────────────┴────────────┐
          │                         │
   sockaddr_in (IPv4)       sockaddr_in6 (IPv6)
   ├── sin_family = AF_INET  ├── sin6_family = AF_INET6
   ├── sin_port              ├── sin6_port
   ├── sin_addr              ├── sin6_addr
   │   └── s_addr (4 bytes)  │   └── s6_addr[16] (16 bytes)
   └── sin_zero[8]           ├── sin6_flowinfo
                             └── sin6_scope_id

sockaddr_storage (通用容器, 可存储 IPv4 或 IPv6)
   └── ss_family ──► 判断是 AF_INET 还是 AF_INET6, 再转型
  1. 统一接口与多协议支持 (struct sockaddr)
    • 早期的网络函数(如 bind, connect, accept)设计时还没有 IPv6, 为了让这些函数既能处理 IPv4, 又能处理 IPv6 甚至未来的新协议, C 语言通过 struct sockaddr 实现类似于面向对象中"基类指针"的概念
    • 编写代码实际操作的是具体的 sockaddr_in(IPv4)或 sockaddr_in6(IPv6), 但在传给系统函数时, 需要强制转换为 struct sockaddr *
  2. 现代网络编程的标准流程 (struct addrinfo 与 getaddrinfo)
    • 过去需要手动填写 IP 地址和端口, 判断是 IPv4 还是 IPv6, 繁琐且不兼容
    • 现代网络编程推荐使用 getaddrinfo 函数来进行DNS解析和地址配置
    • struct addrinfo 串联了整个查询过程. getaddrinfo 返回一个 addrinfo 链表, 程序可以遍历这个链表, 依次尝试连接
  3. 处理不同类型的网络地址 (sockaddr_in 与 sockaddr_in6)
    • 当需要绑定一个端口监听, 或者主动连接一个服务器时, 必须明确告诉操作系统要用哪个 IP 和端口
    • sockaddr_in 用于配置 IPv4 地址和端口, sockaddr_in6 用于配置 IPv6 地址和端口
    • 端口号必须使用 htons() 函数转换为大端序
  4. 通用接收函数 (struct sockaddr_storage)
    • 使用 recvfrom 接收来自未知客户端的数据包时, 你事先并不知道对方是 IPv4 还是 IPv6 客户端
    • sockaddr_storage 的空间足够大, 能够容纳任何类型的地址结构. 可以用它作为通用容器先接住客户端地址, 再通过检查 ss_family 字段来判断到底是哪种协议, 从而安全地进行类型转换

System Call

getaddrinfo() -> socket() -> bind() -> connect() -> listen() -> accept() -> send()/recv() -> sendto()/recvfrom() -> close()/shutdown() -> getpeername() -> gethostname()

getaddrinfo()

#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>

/**
 * node: 域名/IP
 * service: 端口
 * hints: addrinfo 结构
 * res: 输出, 指向 addrinfo 链表的指针
 *
 * Tip
 * 1. C 函数内为外部指针变量分配内存, 则参数需传递二级指针(如 getaddrinfo 内 `*res = malloc(sizeof(struct addrinfo));`), 一级指针只能操作局部变量
 */
int getaddrinfo(const char *node, const char *service, const struct addrinfo *hints, struct addrinfo **res);
  1. 做什么
    • 进行 DNS 解析, 把域名转换成 IP 地址
    • 把服务名(如 http)转换成对应的端口号(如 80)
    • 同时支持 IPv4 和 IPv6, 并能处理一个域名对应多个 IP 的情况
  2. 返回什么
    • 一个链表 (res): 包含所有符合条件的 IP 地址和端口配置信息的链表
    • 状态码

使用 getaddrinfo 查询并显示指定主机名对应的所有 IP 地址

#include <stdio.h>      // printf, fprintf, sprintf 等标准输入输出函数定义在 <stdio.h> 头文件中, 属于标准 C 库
#include <string.h>     // memset, strlen 等字符串操作函数定义在 <string.h> 头文件中, 属于标准 C 库
#include <sys/types.h>  // 基本系统数据类型(如 size_t, ssize_t 等)定义在 <sys/types.h> 头文件中, 属于 POSIX 标准
#include <sys/socket.h> // socket 相关函数(如 socket, bind, connect 等)和数据结构定义在 <sys/socket.h> 头文件中, 属于 POSIX 标准
#include <netdb.h>      // getaddrinfo, freeaddrinfo, gai_strerror 等网络数据库操作函数定义在 <netdb.h> 头文件中, 属于 POSIX 标准
#include <arpa/inet.h>  // inet_ntop, inet_pton 等 IP 地址转换函数定义在 <arpa/inet.h> 头文件中, 属于 POSIX 标准
#include <netinet/in.h> // sockaddr_in, sockaddr_in6, INET6_ADDRSTRLEN 等网络地址结构体和常量定义在 <netinet/in.h> 头文件中, 属于 POSIX 标准

/** gcc main.c -o showip ; ./showip www.baidu.com */
int main(int argc, char *argv[]) {
    /**
     * hints: 查询结构体
     * res: 指向 getaddrinfo 返回的链表头部的指针
     * p: 用于遍历 res 链表的临时指针
     */
    struct addrinfo hints, *res, *p;

    int status;

    /** 用于存放转换后的可读 IP 地址字符串(支持 IPv4 和 IPv6, INET6_ADDRSTRLEN 是最大长度) */
    char ipstr[INET6_ADDRSTRLEN];

    /** 检查命令行参数是否合法, 程序期望接收一个参数: 运行时的程序名(argv[0]) + 要查询的主机名(argv[1]) */
    if (argc != 2) {
        fprintf(stderr, "usage: showip hostname\n");
        return 1;
    }

    /** 初始化并配置 hints 结构体, 将 hints 结构体内存清零, 避免脏数据影响 */
    memset(&hints, 0, sizeof hints);
    
    /** 设置地址族为 AF_UNSPEC, 表示同时接受 IPv4 (AF_INET) 和 IPv6 (AF_INET6) */
    hints.ai_family = AF_UNSPEC;
    
    /** 设置套接字类型为面向连接的流式套接字(TCP) */
    hints.ai_socktype = SOCK_STREAM;

    /** getaddrinfo 函数获取IP地址信息链表 */
    status = getaddrinfo(argv[1], NULL, &hints, &res);
    if (status != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(status));
        return 2;
    }

    printf("IP addresses for %s:\n\n", argv[1]);

    /** 遍历 getaddrinfo 返回的 addrinfo 链表 */
    for (p = res; p != NULL; p = p->ai_next) {
        void *addr;     // 用于指向具体 IP 地址结构体中的地址字段
        char *ipver;    // 用于保存当前 IP 版本的字符串描述("IPv4" 或 "IPv6")

        // 判断当前节点是 IPv4 还是 IPv6
        if (p->ai_family == AF_INET) { // IPv4
            // 将通用套接字地址指针转换回具体的 IPv4 结构体指针 (struct sockaddr_in)
            struct sockaddr_in *ipv4 = (struct sockaddr_in *)p->ai_addr;
            addr = &(ipv4->sin_addr);  // 获取 in_addr 结构体(内部存储 32 位二进制 IP)的地址
            ipver = "IPv4";            // 标记版本为 IPv4
        } else { // IPv6
            // 将通用套接字地址指针转换回具体的 IPv6 结构体指针 (struct sockaddr_in6)
            struct sockaddr_in6 *ipv6 = (struct sockaddr_in6 *)p->ai_addr;
            addr = &(ipv6->sin6_addr); // 获取 in6_addr 结构体(内部存储 128 位二进制 IP)的地址
            ipver = "IPv6";            // 标记版本为 IPv6
        }

        /** 将二进制的 IP 地址转换为点分十进制(IPv4)或冒号十六进制(IPv6)字符串
         * 参数1: 地址族 (AF_INET 或 AF_INET6)
         * 参数2: 指向二进制 IP 地址的指针
         * 参数3: 目标缓冲区 ipstr, 用于存放转换后的字符串
         * 参数4: 缓冲区的大小
         */
        inet_ntop(p->ai_family, addr, ipstr, sizeof ipstr);

        printf("  %s: %s\n", ipver, ipstr);
    }

    /** 释放由 getaddrinfo 动态分配的内存链表, 防止内存泄漏 */
    freeaddrinfo(res); 

    return 0;
}

socket()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * domain: 域, 决定使用哪种网络地址体系 (IPv4/IPv6)
 * type: 通信类型 (流式/数据报/...)
 * protocol: 具体协议 (0/TCP/UDP)
 */
int socket(int domain, int type, int protocol);
  1. 做什么: 创建一个 socket, 指定了协议族与通信类型
  2. 返回什么: 返回一个 socket 文件描述符(fd), 通过该 fd 进行后续网络操作

直接消费 getaddrinfo 的查询结果

int s;
struct addrinfo hints, *res;

getaddrinfo("www.example.com", "http", &hints, &res);

s = socket(res->ai_family, res->ai_socktype, res->ai_protocol);

bind()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 由 socket() 返回的文件描述符
 * addr: 指向 socket 地址结构的指针
 * addrlen: 地址结构的大小
 */
int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
  1. 做什么: 把一个已经创建的 socket 绑定到本地地址, 即指定这个 socket 使用哪个本地 IP 和 port
  2. 返回什么: 状态码

直接消费 getaddrinfo() 的 addr

getaddrinfo(NULL, "3490", &hints, &res);

int sockfd = socket(
    res->ai_family,
    res->ai_socktype,
    res->ai_protocol
);

int result = bind(sockfd, res->ai_addr, res->ai_addrlen);

connect()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 由 socket() 返回的文件描述符
 * serv_addr: 指向远端服务器地址结构的指针
 * addrlen: 服务器地址结构的大小
 */
int connect(int sockfd, const struct sockaddr *serv_addr, socklen_t addrlen);
  1. 做什么: 客户端主动连接服务器, 使用远端服务器的 IP 和 port, 把一个 socket 连接到目标主机
  2. 返回什么: 成功返回 0, 失败返回 -1, 并设置 errno

客户端不调用 bind(), kernel 会自动选择一个可用的 local port. 连接建立后, 服务器可以从连接中获得客户端地址信息

直接消费 getaddrinfo() 的 addr

struct addrinfo hints, *res;
int sockfd;

memset(&hints, 0, sizeof hints);
hints.ai_family = AF_UNSPEC;
hints.ai_socktype = SOCK_STREAM;

getaddrinfo("www.example.com", "3490", &hints, &res);

sockfd = socket(
    res->ai_family,
    res->ai_socktype,
    res->ai_protocol
);

int result = connect(sockfd, res->ai_addr, res->ai_addrlen);

listen()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 由 socket() 返回, 并已通过 bind() 绑定本地地址的 socket 文件描述符
 * backlog: incoming queue 中允许排队等待 accept() 的连接数量
 */
int listen(int sockfd, int backlog);
  1. 做什么: 把 server socket 设置为监听状态, 等待进入的客户端连接
  2. backlog 做什么: 限制尚未被 accept() 处理的连接在 incoming queue 中排队的数量. 常见系统默认限制约为 20, 可以先设置为 5 或 10
  3. 返回什么: 成功返回 0, 失败返回 -1, 并设置 errno

服务端调用 listen() 前需要先调用 bind(), 以便在指定的 local port 上运行:

getaddrinfo();
socket();
bind();
listen();
/* accept() 从这里开始 */

listen() 只负责开始监听和管理等待队列, 真正取出并处理客户端连接由后续的 accept() 完成.

accept()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 正在 listen() 的 socket 文件描述符
 * addr: 用于接收客户端 IP 和 port 的地址结构
 * addrlen: 调用前是 addr 的容量, 调用后是实际写入的地址长度
 */
int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
  1. 做什么: 从 incoming queue 中取出一个 pending connection, 并为这个连接创建一个新的 socket 文件描述符
  2. 返回什么: 成功返回新的 connected socket 文件描述符, 失败返回 -1, 并设置 errno

调用 accept() 后会有两个 socket 文件描述符:

  • sockfd: 原来的 listening socket, 继续等待其他客户端连接
  • new_fd: 新的 connected socket, 用于和当前客户端进行 send() 与 recv()

addr 通常指向 struct sockaddr_storage. 调用前必须把 addrlen 设置为地址结构的大小, 调用后它会被更新为实际写入的地址长度:

struct sockaddr_storage their_addr;
socklen_t addr_size = sizeof their_addr;

int new_fd = accept(
    sockfd,
    (struct sockaddr *)&their_addr,
    &addr_size
);

完整的服务端调用顺序:

struct sockaddr_storage their_addr;
socklen_t addr_size;
struct addrinfo hints, *res;
int sockfd, new_fd;

memset(&hints, 0, sizeof hints);
hints.ai_family = AF_UNSPEC;
hints.ai_socktype = SOCK_STREAM;
hints.ai_flags = AI_PASSIVE;

getaddrinfo(NULL, "3490", &hints, &res);

sockfd = socket(res->ai_family, res->ai_socktype, res->ai_protocol);
bind(sockfd, res->ai_addr, res->ai_addrlen);
listen(sockfd, 10);

addr_size = sizeof their_addr;
new_fd = accept(sockfd, (struct sockaddr *)&their_addr, &addr_size);

/* 使用 new_fd 调用 send() 和 recv() */

如果只需要接受一个连接, 可以在 accept() 成功后用 close(sockfd) 关闭 listening socket, 避免继续接受连接.

send()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 要发送数据的 connected socket 文件描述符
 * msg: 指向待发送数据的指针
 * len: 要发送的数据长度, 单位为 byte
 * flags: 控制发送行为的 flags, 不需要特殊行为时设置为 0
 */
ssize_t send(int sockfd, const void *msg, size_t len, int flags);
  1. 做什么: 通过 stream socket 或 connected datagram socket 发送数据
  2. 返回什么: 成功返回实际发送的 byte 数量, 失败返回 -1, 并设置 errno
char *msg = "Beej was here!";
size_t len = strlen(msg);

ssize_t bytes_sent = send(sockfd, msg, len, 0);

send() 返回的数量可能小于 len, 表示只发送了部分数据. 此时需要从尚未发送的位置继续调用 send():

size_t total = 0;

while (total < len) {
    ssize_t bytes_sent = send(sockfd, msg + total, len - total, 0);

    if (bytes_sent == -1) {
        break;
    }

    total += bytes_sent;
}

recv()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 要读取数据的 connected socket 文件描述符
 * buf: 用于保存接收数据的 buffer
 * len: buffer 最多可以接收的 byte 数量
 * flags: 控制接收行为的 flags, 不需要特殊行为时设置为 0
 */
ssize_t recv(int sockfd, void *buf, size_t len, int flags);
  1. 做什么: 从 stream socket 或 connected datagram socket 接收数据, 并写入 buf
  2. 返回什么:
  • 大于 0: 实际接收并写入 buf 的 byte 数量
  • 等于 0: 远端已经关闭连接
  • 等于 -1: 接收失败, 并设置 errno
char buf[1024];
ssize_t bytes_received = recv(sockfd, buf, sizeof buf, 0);

if (bytes_received == 0) {
    /* 远端已关闭连接 */
}

send() 和 recv() 用于已经建立连接的 socket. 常规的 unconnected datagram socket 应使用 sendto() 和 recvfrom().

sendto()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 用于发送数据的 datagram socket 文件描述符
 * msg: 指向待发送数据的指针
 * len: 要发送的数据长度, 单位为 byte
 * flags: 控制发送行为的 flags, 不需要特殊行为时设置为 0
 * to: 目标主机的 IP 和 port
 * tolen: to 指向的地址结构大小
 */
ssize_t sendto(
    int sockfd,
    const void *msg,
    size_t len,
    int flags,
    const struct sockaddr *to,
    socklen_t tolen
);
  1. 做什么: 通过 unconnected datagram socket 向指定目标发送一个 datagram
  2. 返回什么: 成功返回实际发送的 byte 数量, 失败返回 -1, 并设置 errno

to 可以直接使用 getaddrinfo() 返回的目标地址:

ssize_t bytes_sent = sendto(
    sockfd,
    msg,
    strlen(msg),
    0,
    res->ai_addr,
    res->ai_addrlen
);

recvfrom()

#include <sys/types.h>
#include <sys/socket.h>

/**
 * sockfd: 用于接收数据的 datagram socket 文件描述符
 * buf: 用于保存接收数据的 buffer
 * len: buffer 最多可以接收的 byte 数量
 * flags: 控制接收行为的 flags, 不需要特殊行为时设置为 0
 * from: 用于接收来源主机的 IP 和 port
 * fromlen: 调用前是 from 的容量, 调用后是实际写入的地址长度
 */
ssize_t recvfrom(
    int sockfd,
    void *buf,
    size_t len,
    int flags,
    struct sockaddr *from,
    socklen_t *fromlen
);
  1. 做什么: 从 datagram socket 接收一个 datagram, 同时取得发送方的 IP 和 port
  2. 返回什么: 成功返回实际接收的 byte 数量, 失败返回 -1, 并设置 errno

from 通常使用 struct sockaddr_storage, 这样可以同时容纳 IPv4 和 IPv6 地址. 调用前必须初始化 fromlen:

char buf[1024];
struct sockaddr_storage from;
socklen_t fromlen = sizeof from;

ssize_t bytes_received = recvfrom(
    sockfd,
    buf,
    sizeof buf,
    0,
    (struct sockaddr *)&from,
    &fromlen
);

sendto() 和 recvfrom() 的前四个参数作用相同, 后两个地址参数不一样:

  • sendto(): to 和 tolen 是 input, 指定数据要发给谁
  • recvfrom(): from 和 fromlen 是 output, 返回数据来自谁
  • sendto() 的 tolen 按值传递
  • recvfrom() 的 fromlen 按指针传递, 因为函数需要更新实际地址长度

如果 datagram socket 已经调用 connect(), 仍然使用 UDP 传输 datagram, 但可以直接用 send() 和 recv(), 由 socket interface 自动处理目标和来源地址.

close()

#include <unistd.h>

/**
 * fd: 要关闭的 socket 文件描述符
 */
int close(int fd);
  1. 做什么: 关闭并释放 socket 文件描述符, 此后不能再通过它发送或接收数据
  2. 返回什么: 成功返回 0, 失败返回 -1, 并设置 errno
close(sockfd);

close() 的作用是减少引用计数, 而不是立即销毁 socket. 子进程 close 的是子进程的 socket 引用计数, 对父进程的引用计数无影响.

close() 是通用的 UNIX file descriptor 关闭函数. 在 Windows Winsock 中应使用 closesocket(), 而不是 close().

shutdown()

#include <sys/socket.h>

/**
 * sockfd: 要停止通信的 socket 文件描述符
 * how: 指定停止接收、发送或双向通信
 */
int shutdown(int sockfd, int how);
  1. 做什么: 有选择地停止 socket 的接收方向、发送方向或双向通信
  2. 返回什么: 成功返回 0, 失败返回 -1, 并设置 errno

how 可以使用以下值:

  • SHUT_RD: 不允许再接收数据, 对应数值 0
  • SHUT_WR: 不允许再发送数据, 对应数值 1
  • SHUT_RDWR: 不允许再接收和发送数据, 对应数值 2
shutdown(sockfd, SHUT_WR);

shutdown() 与 close() 不一样:

  • shutdown() 改变 socket 的通信能力, 但不会关闭或释放文件描述符
  • close() 关闭并释放文件描述符
  • 即使调用 shutdown(sockfd, SHUT_RDWR), 最后仍然需要调用 close(sockfd)
shutdown(sockfd, SHUT_RDWR);
close(sockfd);

对于 datagram socket, shutdown() 只能用于已经调用 connect() 的 socket. 它不会把 UDP 变成 stream protocol, 只是禁止后续的发送或接收操作.

getpeername() 与 gethostname()

getpeername()

#include <sys/socket.h>

/**
 * sockfd: connected socket 文件描述符
 * addr: 用于接收对端网络地址的地址结构
 * addrlen: 调用前是 addr 的容量, 调用后是实际写入的地址长度
 */
int getpeername(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
  1. 做什么: 查询 connected socket 对端的 IP 和 port
  2. 返回什么: 成功返回 0, 失败返回 -1, 并设置 errno

addr 通常使用 struct sockaddr_storage, 以便同时容纳 IPv4 和 IPv6 地址. 调用前必须初始化 addrlen:

struct sockaddr_storage peer_addr;
socklen_t peer_addrlen = sizeof peer_addr;

int result = getpeername(
    sockfd,
    (struct sockaddr *)&peer_addr,
    &peer_addrlen
);

取得地址后, 可以使用 inet_ntop() 将 IP 转为文本, 或使用 getnameinfo() 查询可读的 host 和 service 信息. getpeername() 不能取得对端用户的登录帐号.

gethostname()

#include <unistd.h>

/**
 * hostname: 用于接收当前计算机 hostname 的字符数组
 * size: hostname buffer 的大小, 单位为 byte
 */
int gethostname(char *hostname, size_t size);
  1. 做什么: 查询运行当前程序的计算机 hostname
  2. 返回什么: 成功返回 0, 失败返回 -1, 并设置 errno
char hostname[256];

int result = gethostname(hostname, sizeof hostname);

两者查询的对象不同:

  • getpeername(): 查询 socket 连接对端是谁, 返回网络地址和 port, 必须提供 connected socket
  • gethostname(): 查询当前计算机叫什么, 返回 hostname, 不需要 socket

简易 TCP 服务器

Server

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>
#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <netdb.h>
#include <arpa/inet.h>

#define PORT "3490"     // 定义服务器监听的端口号
#define BACKLOG 10      // 定义待处理连接队列的最大长度(未accept的连接数)

/** 从 sockaddr 结构体中提取 IP 地址指针
 * - 如果是 IPv4 地址, 转换为 `struct sockaddr_in` 并返回 `sin_addr`
 * - 否则作为 IPv6 地址处理, 返回 sin6_addr
 * 
 * Tips
 * 1. `&` 取址, `*` 取值
 * 2. `void *` 表示指向未知类型的指针
 */
void *get_in_addr(struct sockaddr *sa) {
    if (sa->sa_family == AF_INET) {
        return &(((struct sockaddr_in *)sa)->sin_addr);
    }
    return &(((struct sockaddr_in6 *)sa)->sin6_addr);
}

/** Tip: `void` 明确声明不接受任何参数 */
int main(void) {
    int sockfd, new_fd;
    struct addrinfo hints, *servinfo, *p;
    struct sockaddr_storage their_addr;
    socklen_t sin_size;
    int yes = 1;
    char s[INET6_ADDRSTRLEN];
    int rv;

    memset(&hints, 0, sizeof hints);    // 清空并初始化 hints 结构体
    hints.ai_family = AF_UNSPEC;        // 不限制 IPv4 或 IPv6 (Unspecified)
    hints.ai_socktype = SOCK_STREAM;    // 使用面向连接的 TCP 流套接字
    hints.ai_flags = AI_PASSIVE;        // 自动填充本地 IP 地址(用于 bind)

    rv = getaddrinfo(NULL, PORT, &hints, &servinfo);    // 获取本地的地址信息链表
    if (rv != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(rv));
    }

    /** 遍历返回的地址链表, 直到成功创建套接字并绑定为止 */
    for (p = servinfo; p != NULL; p = p->ai_next) {
        sockfd = socket(p->ai_family, p->ai_socktype, p->ai_protocol);  // 创建套接字
        if (sockfd == -1) {
            perror("server: socket");
            continue;
        }

        /** 设置套接字选项: 允许地址重用 */
        if (setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &yes, sizeof(int)) == -1) {
            perror("setsockopt");
            exit(1);
        }

        /** 将套接字绑定到本地端口 */
        if (bind(sockfd, p->ai_addr, p->ai_addrlen) == -1) {
            close(sockfd);
            perror("server: bind");
            continue;
        }

        break;
    }

    if (p == NULL) {
        fprintf(stderr, "server: failed to bind\n");
        return 2;
    }

    {
        char ip_str[INET6_ADDRSTRLEN];
        int port;

        /** 将二进制 IP 地址转换为可读字符串 */
        inet_ntop(p->ai_family, get_in_addr(p->ai_addr), ip_str, sizeof(ip_str));

        /** 提取并转换端口号网络字节序为主机字节序 */
        if (p->ai_family == AF_INET) {
            port = ntohs(((struct sockaddr_in *)p->ai_addr)->sin_port);
        }
        else {
            port = ntohs(((struct sockaddr_in6 *)p->ai_addr)->sin6_port);
        }

        printf("server: successfully bound to IP: %s, Port: %d\n", ip_str, port);
    }

    freeaddrinfo(servinfo); // 地址信息链表使用完毕, 释放内存

    if (listen(sockfd, BACKLOG) == -1) {    // 开始监听端口, BACKLOG 指定队列长度
        perror("listen");
        exit(1);
    }
    
    printf("server: waiting for connections...\n");

    /** 服务器主循环: 持续接受客户端连接 */
    while(1) {
        sin_size = sizeof their_addr;
        /** 阻塞等待并接受一个客户端连接, 返回新的套接字描述符 new_fd */
        new_fd = accept(sockfd, (struct sockaddr *)&their_addr, &sin_size);
        if (new_fd == -1) {
            perror("accept");
            continue;
        }

        /** 将客户端的二进制 IP 地址转换为可读的字符串形式 -> s */
        inet_ntop(their_addr.ss_family, get_in_addr((struct sockaddr *)&their_addr), s, sizeof s);
        printf("server: got connection from %s\n", s);

        /** 当前连接处理完成前, 服务器不会 accept 下一个连接 */
        if (send(new_fd, "Hello world!", 13, 0) == -1) {
            perror("send");
        }

        close(new_fd);      // 关闭当前连接, 继续等待下一个连接
    }

    return 0;
}

Client

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>
#include <netdb.h>
#include <sys/types.h>
#include <netinet/in.h>
#include <sys/socket.h>
#include <arpa/inet.h>

#define PORT "3490"             // Client 所要连接的 port
#define MAXDATASIZE 100         // 一次可以收到的最大字节数量(number of bytes)


void *get_in_addr(struct sockaddr *sa) {
    if (sa->sa_family == AF_INET) {
        return &(((struct sockaddr_in *)sa)->sin_addr);
    }
    return &(((struct sockaddr_in6 *)sa)->sin6_addr);
}

int main(int argc, char *argv[]) {
    int sockfd, numbytes;
    char buf[MAXDATASIZE];
    struct addrinfo hints, *servinfo, *p;
    int rv;
    char s[INET6_ADDRSTRLEN];

    if (argc != 2) {
        fprintf(stderr,"usage: client hostname\n");
        exit(1);
    }

    memset(&hints, 0, sizeof hints);
    hints.ai_family = AF_UNSPEC;
    hints.ai_socktype = SOCK_STREAM;

    if ((rv = getaddrinfo(argv[1], PORT, &hints, &servinfo)) != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(rv));
        return 1;
    }

    for(p = servinfo; p != NULL; p = p->ai_next) {
        if ((sockfd = socket(p->ai_family, p->ai_socktype, p->ai_protocol)) == -1) {
            perror("client: socket");
            continue;
        }

        if (connect(sockfd, p->ai_addr, p->ai_addrlen) == -1) {
            close(sockfd);
            perror("client: connect");
            continue;
        }

        break;
    }

    if (p == NULL) {
        fprintf(stderr, "client: failed to connect\n");
        return 2;
    }

    inet_ntop(p->ai_family, get_in_addr((struct sockaddr *)p->ai_addr), s, sizeof s);
    printf("client: connecting to %s\n", s);

    freeaddrinfo(servinfo);

    /** 从已连接的套接字接收数据 -> buf
     * Tip
     * 1. 就算不 recv 实际也已收到消息
     */
    if ((numbytes = recv(sockfd, buf, MAXDATASIZE-1, 0)) == -1) {
        perror("recv");
        exit(1);
    }

    /** 接收到的数据末尾添加字符串结束符, 将原始字节数据转换为 C 语言标准的字符串
     * Tip
     * 1. C 语言中的字符串必须以 空字符 '\0'(ASCII 0) 结尾
     */
    buf[numbytes] = '\0';
    printf("client: received '%s'\n",buf);

    close(sockfd);
    return 0;
}
